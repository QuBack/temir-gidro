# SEO-аудит нового сайта ТЕМИР ГИДРО (Django)

Дата: 02.10.2026 · Объект: локальная копия сайта (`localhost:8000`, ветка `old-site-specs`) · Приоритет: Яндекс, затем Google.
Методика: скиллы `seo-audit` (общий аудит) и `yandex-seo` (особенности Яндекса). Обход всех внутренних ссылок, проверка кода шаблонов и настроек.

## Итог

**SEO Health Score: 74 / 100.** Тип бизнеса: B2B-производитель оборудования (гидравлические подъёмники, гидроцилиндры), Москва, поставки по России.

Техническая база сделана хорошо: один канонический адрес, robots.txt с `Clean-param`, автоматический sitemap, разметка на каждой странице, картинки AVIF/WebP с размерами и `alt`, минимум JavaScript, заголовки безопасности. Главные потери — не в технике, а в том, что Яндекс называет **коммерческими факторами**: на сайте нет цен, отзывов, реквизитов, страницы доставки и реальных объектов. И самое срочное — переезд со старого сайта без 301-редиректов потеряет накопленные позиции.

| Категория | Вес | Оценка |
|---|---|---|
| Техническое SEO | 22% | 80 |
| Контент | 23% | 60 |
| On-page (title, description, заголовки, ссылки) | 20% | 82 |
| Микроразметка | 10% | 70 |
| Скорость (оценка по коду, без замеров) | 10% | 80 |
| Готовность к ИИ-поиску (Алиса, нейроответы) | 10% | 65 |

### 5 главных проблем
1. **Нет 301-редиректов со старого сайта temir-gidro.ru.** Таблица соответствия адресов готова (в `todo.md`), но в коде редиректов нет. После переезда старые страницы отдадут 404, позиции обнулятся.
2. **Политика конфиденциальности — заглушка** («Текст политики будет добавлен»), а формы собирают имя и телефон. Это нарушение 152-ФЗ и минус к доверию.
3. **Ссылка на несуществующую страницу `/dostavka-i-oplata/` в подвале каждой страницы** (24 битые ссылки).
4. **Коммерческие факторы почти не закрыты:** нет цен «от …», отзывов, реквизитов (ИНН/ОГРН), срока гарантии, сертификатов, мессенджеров для связи.
5. **Нет реальных кейсов.** Блок «Решения под объект» — обобщённые сцены без города, заказчика и результата; для Яндекса и для покупателя это слабое доказательство опыта.

### 5 быстрых побед
1. Убрать или сделать страницу «Доставка и оплата» — 1 час.
2. Добавить в sitemap `lastmod` для всех страниц (сейчас только у 4 статей из 23 адресов).
3. `og:locale` → `ru_RU`, сократить 4 слишком длинных title (до ~70 символов).
4. Заполнить почтовый индекс и координаты в разметке организации (сейчас `postalCode: ""`).
5. Включить в Метрике Вебвизор и добавить цели на клики по соцсетям/мессенджерам.

## 1. Техническое SEO — 80

**Что хорошо**
- 24 страницы отвечают 200, редиректов-цепочек нет; адрес без слеша → 301 на адрес со слешем; несуществующий адрес → 404.
- На каждой индексируемой странице свой `rel=canonical`; адрес с `?utm_source=` канонизируется на чистый.
- robots.txt: без устаревших `Host` и `Crawl-delay`, есть `Clean-param` для utm/yclid/gclid, ссылка на sitemap. На тестовом сервере (`SEO_INDEXING=False`) сайт закрывается целиком.
- Страницы заявки и «спасибо» — `noindex, follow`; админка закрыта логином.
- Заголовки безопасности: CSP, `X-Frame-Options: DENY`, `nosniff`, `Referrer-Policy`; HSTS и редирект на HTTPS включаются в боевом режиме.
- Caddy: сжатие zstd/gzip, редирект www → без www (одно главное зеркало).

**Проблемы**
| Важность | Что | Где / доказательство | Что сделать |
|---|---|---|---|
| Critical | Нет 301 со старого сайта | `urls.py` — редиректов нет; список старых адресов в `todo.md` и `temir-gidro.ru-audit/ACTION-PLAN.md` | Сделать постраничные 301 (`/equipment/temir-gidro-1x/` → `/podemniki/nozhnichnye/1x/` и т. д.), 410 для `/feed/`, `/wp-json/`. Если меняется домен — 301 со всего старого домена + «Переезд сайта» в Вебмастере |
| High | Битая ссылка в подвале | `/dostavka-i-oplata/` → 404, ссылка на всех 24 страницах | Сделать страницу (это ещё и коммерческий фактор) или временно убрать ссылку |
| Medium | `lastmod` только у 4 из 23 URL | `sitemap.xml` | Отдавать дату изменения для всех страниц (хотя бы дату последнего деплоя контента) |
| Medium | Нет IndexNow | — | Ключ-файл в корне + отправка изменённых URL при деплое (Яндекс и Bing) |
| Low | Иконка сайта 32×32, `/favicon.ico` → 404 | `<link rel=icon>` на `favicon-32.png` | Яндекс показывает фавикон в выдаче: добавить SVG или PNG от 120×120 и отдать `/favicon.ico` |
| Low | hreflang только `ru` + `x-default` | — | Не вредит; пригодится, когда появятся другие языки |
| Info | Скорость ответа ~2 с | dev-сервер Windows (`localhost`) | Не показатель: замерить на сервере |

## 5. Скорость — 80 (оценка по коду)

Полевых данных нет (сайт не опубликован), лабораторный замер в этом окружении невозможен. По коду:
- Картинки — AVIF + WebP, `srcset`/`sizes`, `width`/`height`, `loading="lazy"` ниже первого экрана, главная картинка — `fetchpriority="high"`.
- JS — 6 небольших файлов (≈30 КБ без сжатия), все `defer`; Метрика грузится после `load`.
- Шрифты self-hosted, woff2, `preload` основных начертаний.
- CSS один файл, 73 КБ без сжатия (≈15 КБ gzip).
- Вес страницы после первой прокрутки ≈0,5 МБ (без сжатия, dev-сервер).

После запуска: PageSpeed Insights для главной, линейки и модели (мобайл), цель LCP < 2,5 с, CLS < 0,1, INP < 200 мс.

### Региональность
- Регион в Вебмастере: Москва (или «Россия», если продажи равномерно по стране) — решить с заказчиком.
- **Яндекс Бизнес:** карточка с тем же адресом, телефоном и часами, что на сайте (NAP), фото производства, услуги, отзывы с ответами.

### Вебмастер и Метрика
- ✅ Метрика: точный показатель отказов, карта кликов, цели `lead_sent`, `config_sent`, `phone_click`, `email_click`.
- ⚠️ Вебвизор выключен (`webvisor: false`) — без него сложно разбирать поведение; включить (с уведомлением о cookie по 152-ФЗ).
- ⚠️ Нет целей на клики по соцсетям; нет цели на страницу «спасибо» для заявок без JS (настроить в интерфейсе Метрики).
- После запуска: подтвердить права, связать Вебмастер ↔ Метрику («Обход по счётчикам»), добавить sitemap, регион, проверить «Страницы в поиске → Исключённые».

### Чего не делать
Накрутка ПФ, покупка ссылок, SEO-тексты ради ключей, Турбо-страницы (отключены в 2025), директивы `Host`/`Crawl-delay`.
