# 2L — модель для проверки

- Просмотр: `http://127.0.0.1:8767/docs/models/2l/`.
- `2l.glb` — самостоятельный файл для загрузки на сайт; текстуры встроены.
- `output/models/2l/2l.blend` — итоговый Blender, геометрия объединена для веб-экспорта.
- `output/models/2l/2l-working.blend` — редактируемая сборка с отдельными деталями до веб-оптимизации.
- `output/models/2l/session-before.blend` — сцена Blender до начала работы.

Источник: `C:/Users/user/Desktop/Подьемники/2l2.max`, сборка `2l2` и её потомки. Геометрия перенесена из исходника, а материалы преобразованы в PBR: красная окраска, оцинкованная сталь, полированные штоки, графитовая платформа, резина. Логотип взят из `maps/2L2.tif` с маской `maps/2L2_logo_mask.tif`; нормаль рифлёного настила рассчитана из `maps/2k_texture_gost_bump.png`.

Габариты исходной сборки после перевода миллиметров в метры: приблизительно 3,16 × 3,10 × 15,02 м. Высота мачт сохранена из MAX. Изображения каталога используются для сверки материалов; длина мачт на них отличается от переданной сборки.

Отдельные части, цепи, крепёж и штоки сохранены при упрощении повторяющейся мелкой геометрии. Количество полигонов уменьшено с 4,35 млн до 935 тыс.; при экспорте применяется Draco. Для редактирования отдельных деталей используйте `2l-working.blend`, для размещения на сайте — GLB.

Импортёр: [Import Autodesk MAX, NRGSille](https://extensions.blender.org/add-ons/io-scene-max/), версия 1.9.2. Конвертация запускается скриптами в `tools/model-conversion/`; импортёр читает большие контейнеры по требованию, чтобы не разворачивать все скрытые сборки сцены. В исходном MAX также обнаружена отдельная сборка `4X2L`, содержащая 11 объектов геометрии. Она не включена в GLB 2L.

HTML использует локальные `static/vendor/model-viewer` и `static/vendor/draco`, а изображения для сравнения — из `static/img/catalog`. Для переноса всей страницы сохраняйте структуру этих путей. Сам GLB независим от HTML и исходных текстур.
