# 4X — ножничный подъёмник

- [Локальный HTML-просмотр](http://127.0.0.1:8767/docs/models/4x/).
- `4x.glb` — самостоятельный файл для сайта, около 2,2 МиБ; все текстуры встроены.
- `output/models/4x/4x-working.blend` — редактируемый Blender с отдельными механизмами и восстановленными материалами.
- `output/models/4x/4x.blend` — объединённая модель для веб-экспорта.
- `output/models/4x/4x-imported.blend` — исходный результат переноса геометрии из MAX.

Источник: `C:/Users/user/Desktop/Подьемники/2l2.max`, отдельная сборка `4X2L`: 11 объектов геометрии, четыре яруса ножниц. Сборка 2L в этот GLB не включена.

Габариты модели после перевода миллиметров в метры: приблизительно 2,25 × 1,91 × 6,08 м. Положение платформы и геометрия ножниц взяты из исходника. Сравнение материалов выполнено по `static/img/catalog/nozhnichnyj-podemnik-4x-800.webp`.

Материалы: красная порошковая окраска рычагов, тёмная рама и платформа, полированный металл штоков и крепежа, тёмные корпуса цилиндров, резина. Логотип извлечён из предоставленных `maps/4xl2_logo.tif` и `maps/4xl2_logo_mask.tif`. Нормаль рифлёного настила рассчитана из предоставленного `maps/2k_texture_gost_bump.png` и повторно использована из подготовки 2L. Рабочие текстуры упакованы в Blender, для GLB используются встроенные PNG.

Число полигонов уменьшено примерно с 359 тыс. до 144 тыс. за счёт упрощения металлического крепежа и штоков. Геометрия основных рычагов и рам сохранена. Веб-модель объединена и сжата Draco.

Проверено: структура GLB 2.0, встроенные текстуры без внешних URI, отображение в Blender и браузере, переключение ракурсов, отсутствие ошибок браузера.

Исправление настила: рифлёный материал назначен также видимому верхнему листу `Object0061`, который закрывал внутреннюю деталь платформы. На верхней поверхности используются цветовая карта из `2k_texture_gost_.jpeg` и карта нормалей, масштаб рисунка задан в метрах. Боковины остаются графитовыми. В HTML добавлен ракурс «Настил» с возвратом к общему виду через остальные кнопки; версия URL GLB обновлена для сброса кэша.

Конвертация использует импортёр MAX 1.9.2 из `output/model-conversion/io_scene_max`. Скрипты: `tools/model-conversion/import_2l.py --assembly 4X2L --slug 4x` (аргументы Blender передаются после `--`), `textures_4x.py`, `finish_4x.py`, `preview_4x.py`. HTML использует существующие локальные `static/vendor/model-viewer` и `static/vendor/draco`.
